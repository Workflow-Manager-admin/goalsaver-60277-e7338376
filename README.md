# goalie-60277-e7338376

This project was formerly called "GoalSaver", and is now named "Goalie"—your playful savings buddy!

---

## Google Calendar Integration

Goalie allows you to sync your savings reminders with Google Calendar!
- Uses secure OAuth 2.0 JS client-side flow.
- Lets you pick or create which Google calendar receives your reminders for each goal.
- No secrets are kept in the repo: you enter your Google client ID locally once.
- See `goal_saver_frontend/README.md` for full instructions.
